
# Day 23 Internship Task - Tip Calculator

## Project Description

The Tip Calculator is a responsive web application that calculates the tip amount and total bill based on the bill amount, selected tip percentage, and number of people sharing the bill.

## Objective

The objective of this project is to practice HTML forms, CSS styling, JavaScript functions, arithmetic calculations, event handling, and input validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Enter the bill amount.
- Select a tip percentage from 5%, 10%, 15%, or 20%.
- Enter a custom tip percentage between 0% and 100%.
- Specify the number of people sharing the bill.
- Calculate the total tip amount.
- Calculate the total bill including the tip.
- Display the tip per person.
- Display the total amount per person.
- Update results automatically when inputs change.
- Validate bill amount, tip percentage, and number of people.
- Reset the calculator to its default values.
- Responsive layout for mobile and desktop screens.

## How to Run the Project

1. Download or copy the project files.
2. Keep all four files in the same folder.
3. Open `index.html` in a web browser.
4. Enter the bill amount.
5. Select a tip percentage or enter a custom percentage.
6. Enter the number of people.
7. View the calculated results.

## Calculation Formula

Tip Amount = Bill Amount × Tip Percentage / 100

Total Bill = Bill Amount + Tip Amount

Tip Per Person = Tip Amount / Number of People

Total Per Person = Total Bill / Number of People
